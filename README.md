# LSTM Password Strength Analyzer

Bu proje, LSTM tabanlı parola tahmin edilebilirlik analizi ve güvenli parola öneri sistemi geliştirmeyi amaçlamaktadır.

## Proje Amacı

Projenin amacı, kullanıcı parolalarının tahmin edilebilirlik düzeyini analiz etmek ve daha güvenli parola önerileri sunmaktır. Sistem, LSTM tabanlı model yaklaşımı ile parola desenlerini inceleyerek zayıf parola yapılarını tespit etmeyi hedefler.
